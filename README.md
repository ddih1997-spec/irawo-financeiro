# IRAWÒ Financeiro

Controle financeiro da casa de axé: receitas, gastos, parcelamentos a receber, baixas e dashboard.
App web (PWA) que usa uma planilha Google como banco de dados e IA (OpenRouter) para lançar por áudio, foto, vídeo ou texto.

Nenhum segredo fica neste repositório: o código de acesso e a chave da IA ficam nas propriedades do Apps Script.
